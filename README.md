# Druid AI Docs

Product help migrated from the MadCap Flare HTML5 Top Navigation output into GitBook Markdown.

GitBook reads this repository as a docs site (`gitbook-docs.yaml`). The help itself is the Documentation space:

- `documentation/.gitbook.yaml` — home page and table of contents
- `documentation/SUMMARY.md` — Flare TOC, in order
- `documentation/Content/` — 980 topics and the images they use

Topic links point at `.md` files. External links are unchanged. See `MIGRATION.md` for the rewrite rules and the counts from the conversion.
