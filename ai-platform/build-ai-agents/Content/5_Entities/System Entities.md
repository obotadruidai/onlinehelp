This section provides description of all system entities, listing the entity fields available. To view detailed information, click on the desired system entity below.

## \[\[BotSettings]]

The \[\[BotSettings]] system entity acts as a central repository for the configuration of your AI Agent. It stores critical information about special flows and general AI Agentsettings that are automatically loaded into the conversation context.

Because this entity is available globally within the conversation context, you can use it to programmatically reference and trigger specific system behaviors without needing to hardcode unique Flow IDs, which may change across different environments or solution imports.

In the Druid Portal, you can view this entity by navigating to **All Settings** > **Entities**.

You can use \[\[BotSettings]]..Id within a Trigger Flow step to dynamically redirect the user to a special flow set in the AI Agent configuration, section Dialogue management.

The following properties are typically available under the \[\[BotSettings]] entity, representing the special flows configured for your AI Agent:

| Special Flow                     |                                                                              |
| -------------------------------- | ---------------------------------------------------------------------------- |
| AuthenticationFlow               | Triggers the flow responsible for user identity verification.                |
| ExceptionFlow                    | Triggers the flow that handles unexpected errors or system failures.         |
| InactivityCancelConversationFlow | Triggers when a conversation is terminated due to user inactivity.           |
| IntentRephraseFlow               | Triggers when the AI Agent needs the user to restate their request.          |
| KnowledgeBaseResponseFlow        | Triggers the default flow for delivering answers from the Knowledge Base.    |
| LanguageChangedFlow              | Triggers when the AI Agent detects or switches to a different language.      |
| NoIntentFlow                     | Triggers when the NLP engine cannot map the user input to a specific intent. |
| VoiceCallTerminateFlow           | Triggers the closing sequence for voice-based interactions.                  |
| WelcomeFlow                      | Triggers the initial greeting or onboarding flow for new sessions.           |
