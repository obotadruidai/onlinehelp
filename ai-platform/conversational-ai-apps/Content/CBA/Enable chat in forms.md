---
title: Enable Chat in Forms
---


Enable business users to interact with the AI Agent directly from a specific record. By clicking the Chat button, users can ask questions about the record or request the AI Agent to perform actions within the record context.

![](<../../.gitbook/assets/chat button on form.png>)

![](<../../.gitbook/assets/record context.png>)

To enable the chat feature on a form, follow these steps:

1. Navigate to the desired form configuration page and click the Chat icon(![](<../../.gitbook/assets/chat bobble.png>)in the right-side editor. This opens the Chat properties panel.
2. Toggle **Active chat** to on.
3. Keep **Visible On load** selected to ensure the chat button is available when the form opens.
4. Choose your preferred display style (Appearance). The default is the chat bubble icon(![](../../.gitbook/assets/appearance.png)).
5. Set default behavior. Select **Open chat by default** if you want the AI Agent panel to automatically expand on the right side of the form, removing the need for the user to click the icon manually.

![](<../../.gitbook/assets/chat by default on form.png>)

6. Configure Interaction (Optional). Enable **Allow edit on chat open** to let users modify form fields while simultaneously interacting with the AI Agent.
7. Optionally, select a **Welcome flow** to trigger as soon as the user opens the chat on this entity record..
8. Save the chat properties.
