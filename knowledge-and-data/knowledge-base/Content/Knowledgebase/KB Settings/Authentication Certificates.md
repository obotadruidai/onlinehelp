title: "Authentication Certificates"
---

<a id="AuthenticationCertificates"></a>


Authentication Certificates lists Druid-generated certificates used to authenticate SharePoint Online data sources. This option is an alternative to a SharePoint client secret. Certificates are created here, downloaded, and uploaded to your Microsoft Entra app registration before you add or test a SharePoint data source.

Use **Add new** to create a certificate, then manage existing entries in the table (Name, Data Source, Valid from, Valid to, Thumbprint). Download a certificate for Azure import, or delete one that is expired or no longer needed. For prerequisites, step-by-step creation, Azure import, data source configuration, and certificate renewal, see [Authenticate with SharePoint by using a Druid-generated certificate](../SharePoint%20data%20sources.md#Authenticate_with_SharePoint_by_using_a_DRUID-generated_certificate) and [Authenticate with SharePoint when the Druid-generated certificate expired](../SharePoint%20data%20sources.md#Authenti).
