title: Webex
---


Druid Portal allows you to create the AI Agent once and deploy it in Webex.

{% hint style="info" %}
**NOTE:** The Webex channel does not support Hero, Choice, Thumbnail and Location steps, but supports Adaptive Cards v2. Do not use Adaptive cards v3 as they will not be rendered in Webex.
{% endhint %}

## Prerequisites

* You built and published an AI Agent.
* You need to have a Webex developer account. If you have not gone an account, sign up [here](https://cart.webex.com/sign-up).
* You need a Webex Sandbox or an admin account to Webex Control Hub. To get a Webex sandbox, follow instructions provided in [Developer Sandbox documentation](https://developer.webex.com/docs/developer-sandbox-guide).
* For DRUID on premise deployments, make sure that you provide access to/from the necessary messaging endpoints as follows:

|          |               |
| -------- | ------------- |
| Outbound | webexapis.com |
| Inbound  | DRUID.BotApp  |

{% hint style="warning" %}
**IMPORTANT!** The Webex channel does not support file download. If you upload a file, the message containing the file is not rendered on Webex.
{% endhint %}

To integrate a DRUID AI Agent with Webex, follow these steps:

## Step 1. Create a Webex bot

1. Log in the [Webex developer portal](https://developer.webex.com/).
2. From the menu under your avatar at the top of this page, select **My Webex Apps**.

![](<../../../.gitbook/assets/my webex apps.png>)

3. Click **Start Building Apps**. The Create a New App page appears.
4. Click **Create a Bot** to start the wizard.

![](<../../../.gitbook/assets/new app page.png>)

5. Provide basic information about the bot: bot name, bot username, and an icon. These fields are end-user facing, so make them as descriptive as possible. Only the bot's first name will be shown when mentioned in messages, so try to avoid spaces in the bot name. The description will be shown to users if you submit your bot to the Webex App Hub.

![](<../../../.gitbook/assets/webex app details.png>)

6. Click the **Add Bot** button. A non-expiring bot access token is generated for the new bot. This access token will be used to authenticate your bot with the Webex REST API. Copy the token and keep it somewhere safe, you need it to set up the webhook.

![](<../../../.gitbook/assets/copy token (1).png>)

{% hint style="info" %}
**Info:** If you misplace the access token, you can always generate a new one by finding the bot in My Webex Apps and clicking **Regenerate Access Token** from the edit page.
{% endhint %}

## Step 2. Activate Webex channel in DRUID

1. In Druid Portal, select the AI Agent you want to deploy in Webex, click the **Channels** tab and then **Webex**. The Webex channel section expands.
2. In the **AI Agent token** field, enter the access token generated in Webex for your AI Agent and click the **Generate** button.

![](<../../../.gitbook/assets/generate secret.png>)

A secret is generated for Webex integration.

3. Copy the **Secret** generated by DRUID and the **Druid url** and keep them somewhere safe.

![](<../../../.gitbook/assets/channel details (1).png>)

4. Click **Publish**. Wait until the Webex channel is activated.

After the channel’s activation, the following fields are available in DRUID:

* **\[\[ChatUser]].ChannelId** = "webex"
* **\[\[ChatUser]].UserId** - Stores an unique identifier of the Webex user account.

## Step 3. Configure the webhook for your Webex bot in Webex Control Hub

1. Go to [Webex Control Hub](https://admin.webex.com/login) and log in.
2. On **Management** menu click **Organization Settings**.
3. Scroll-down to Alerts section. In the **Webhook** field, enter the **Druid url** you copied from and in the **Secret token** field enter the Secret generated by DRUID.

![](<../../../.gitbook/assets/set webhook (1).png>)

4. Click **Save**.
5. On the main menu, click **Alerts center** and then **Manage**.
6. Click **Create rule** and provide the mandatory details.

![](<../../../.gitbook/assets/my alerts.png>)

7. In the Delivery channel section, enable **Webhook**.

![](<../../../.gitbook/assets/ENABLE WEBHOOK.png>)

8. Click **Save**.

## Step 4. Talk to your AI Agent

1. Open your Webex client.
2. On the main menu, click the chat icon, then the + icon at the top and select **Send a direct message**.
3. In the **Search** field, enter the username of your Webex bot.

![](<../../../.gitbook/assets/search bot username.png>)

4. Click **Invite to Webex**. You can now start chatting with the AI Agent. A special badge is added to messages the AI Agent sends so users know they're interacting with a AI Agent instead of a human.

![](<../../../.gitbook/assets/talk to bot.png>)
