# Return to Work

The solution contains return to work conversations after the pandemics. As an employee you can book or cancel your reservation at the office, or verify daily desk availability. The template also includes the list of regulations that must be respected by both the employer and employee.

<a id="Configurethetemplate"></a>

## Configure the template
