# Reports

This solution template provides you with a set of reports from the operational area of financial services. You can see how many tickets were opened in a specific period of time, how many cards were blocked or which was the average customer satisfaction.

Your Customer Service Managers will be able to track the following:

- How many positive feedback comments were received in a given period
- How many positive feedback comments were received in a given period
- How many cards were issued in a given period
- How many cards were unblocked in a given period
- How many tickets were opened in a given period
- How many tickets were solved in a given period
- How many contract changes were done in the last months.

You can personalize the reports and also add other relevant KPIs based on your needs.
