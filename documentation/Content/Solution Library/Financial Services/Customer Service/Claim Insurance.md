# Claim Insurance

This solution templates enables your AI Agent to identify the intent of the user, searches for a valid policy and guides the user through the process of opening a claim file when an incident happens.

<a id="Step1Configurethetemplate"></a>

## Step 1: Configure the template

After you import this solution, configure it following the procedure described in [Configuring Skill Templates](../General%20Settings/Configuring%20Solution%20Templates.md).
