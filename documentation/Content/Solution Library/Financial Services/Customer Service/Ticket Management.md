# Ticket Management

This solution template provides conversational flows and integrations that allow the customer to easily open a new ticket on a specific problem, to add comments or photos to an opened ticket, to check the status of a particular ticket.

The skill includes high-speed response, 24x7 availability, real-time alerts, seamless integration into existing self-service systems and enterprise level security.

<a id="Keybenefits"></a>

## Key benefits

- 24/7 Availability
- Automated Notifications
- Easy Integration with existing ITSM tool. By default, the solution template contains ServiceNow integration.
- Incident Management
- Improved Employee Productivity
