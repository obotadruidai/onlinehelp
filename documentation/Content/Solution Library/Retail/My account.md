# My Account

This solution template provides conversation flows that simplify the shopping experience by allowing the customers to save and use personal information into the "My account" section. From My Account, the customers can save their payment information, set up a favorite delivery address, update their profile, check the available vouchers, etc.

![](../../Resources/Images/Retail/My%20account.png)

| Flow Category | Description |
| --- | --- |
| My Delivery Addresses | Allows the customer to easily set up, add or modify delivery addresses. |
| My payment information | Allows the customer to save into his account the payment information. |
| My profile | Conversational flows that will guide the customer to update/save personal informational (phone number, e-mail, name, etc.) into his account. |
| My reviews | Every item that a person has purchased can be evaluated directly via the conversation with the AI Agent and the customers are encouraged to share their opinions, positive or negative. |

<a id="Configurethetemplate"></a>

## Configure the template

After you import this solution, configure it following the procedure described in [Configuring Skill Templates](General%20Settings/Configuring%20Solution%20Templates.md).

<a id="Seethesolutioninaction"></a>

## See the solution in action

In the chat, type “I want to update my account”

The AI Agent provides the information as it is saved into your user account.

![](../../Resources/Images/Retail/My%20account_1.png)

Type “I want to see my reviews”.

The AI Agent provides your product reviews.

![](../../Resources/Images/Retail/My%20account_2.png)
