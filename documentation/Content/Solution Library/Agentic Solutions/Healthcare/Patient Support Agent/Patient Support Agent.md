# Patient Support Agent

The **Patient Support Agent** is an AI Agent designed for healthcare providers, built on Druid technology. It replaces rigid, menu-driven patient portals with a natural, conversational experience powered by a large language model (LLM). Patients interact through a single AI Agent to manage prescription orders and securely access laboratory results—all without navigating complex interfaces or placing unnecessary calls to clinic staff.

This AI Agent automates high-volume clinical support workflows—such as medication reordering, prescription generation, data collection, and diagnostic result retrieval—while maintaining patient data security and clinical review integrity.

<a id="Skills"></a>

## Skills

- **Order Medication Skill**. An intelligent clinical workflow layer built on top of the Healthcare Agentic Solution that automates the complete prescription lifecycle—from initial creation following an appointment, through ongoing changes, to patient-initiated repeat reorders.
- **Lab Results Skill**. Allows patients to securely access, view, and understand their laboratory results through conversational interactions with the support agent.
