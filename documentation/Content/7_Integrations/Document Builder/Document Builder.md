# Document Builder

<a id="microcontent1"></a>

DRUID’s Document\_Generator app enables authors to automate any document-based process with AI Agents and document templates that contain entity-sourced dynamic data, providing users with Microsoft Excel or Word reports or documents, also adding the flexibility of a built-in PDF generator.

With this connector app, your AI Agent can generate documents on the fly, as follows:

- Generate word, excel and PDF files using document templates.
- Generate a PDF file from a document template (e.g., a contract) and merge it with other PDF files (e.g., appendices).
- Merge PDF files stored in an entity list of files.

> **NOTE:** The Druid AI Platform automatically provisions the **Document\_Generator** connector app, so no need to create it. It is by default available on all tenants and all AI Agents.
