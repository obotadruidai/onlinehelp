## Druid MCP Server for AI Authoring

We are excited to introduce the Druid MCP Server, extending our advanced authoring skills to AI Agents outside the Druid AI Platform! With this release, you have the flexibility to choose whether to author Druid AI Agents using our native, built-in AI Authoring Agents or leverage external coding agents.

<a id="DruidMCPServersforBusinessTransactions"></a>

## Druid MCP Servers for Business Transactions

We are excited to introduce Druid MCP Servers for business transactions, transforming the Druid AI Platform into a secure middle layer between your core business applications and business AI Agents. This capability allows you to orchestrate integrations and API calls to back-office systems with enterprise-grade security and control, exposing them through the Model Context Protocol (MCP) to be consumed by either Druid AI Agents or external coding agents.

This architecture directly solves the critical security and control challenges of executing API calls on top of legacy or back-office systems that do not natively offer MCP servers. For example, if you want to leverage an external coding model while maintaining absolute control over the backend business transactions it might trigger, you can simply add Druid to your preferred coding model by installing the Druid MCP Server and associated skills. This ensures all external agent actions remain securely governed, validated, and audited by Druid before hitting your business applications.

<a id="AIHarnessing"></a>

## AI Harnessing

AI Harnessing introduces a structured framework for enabling AI Agents to execute enterprise tasks more reliably and with greater control. It allows authors to provide reusable instructions that AI Agents can dynamically discover and apply at runtime, while supporting business-rule validation and feedback mechanisms to help ensure actions are executed safely and correctly.

## Interactive Calendar Webchat Widget

During HR interview rescheduling or healthcare appointment management—entering free-text dates can feel cumbersome and prone to formatting errors. An intuitive chat UI enhancement that introduces an interactive calendar widget directly into the webchat interface. Instead of requiring users to manually type out dates and times during scheduling workflows, this feature provides a clickable calendar view for seamless selection.
