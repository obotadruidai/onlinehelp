# Delete Workspaces

> **NOTE:** Only users who have been granted a security role with permission **[Workspace delete]** can delete workspaces. For more information, see [Define Security Roles for Business Users](Define%20Security%20Roles%20for%20Business%20Users.md).

From the **All Settings** menu, click **Workspaces**. The list of work spaces to which you have access displays.

![](../Resources/Images/CBA/WORKSPACES%20LIST.png)

To remove a workspace, click the delete icon (![](../Resources/Images/CBA/delete%20icon.png) ) displayed in line with the workspace. A confirmation dialog appears. Click **Yes**. The dialog closes and the workspace is deleted.
