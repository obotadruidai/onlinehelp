# Troubleshooting Conversation Errors

**Prerequisite**: In the chat, copy the error code, you’ll need it for troubleshooting.

![](<../../../../.gitbook/assets/chat error.png>)

1. On the left menu, click **History & Logs**, then click **Conversation History**. The Conversations History page appears.

![](<../../../../.gitbook/assets/conv history page.png>)

2. Select the AI Agent on which the error occurred.
3. In the **Correlation Identifier** field, enter / paste the error code you copied from the chat.

![](<../../../../.gitbook/assets/search log by corr id.png>)

4. Select the Date range by clicking on the from / to date displayed in the **Date range** field, choose the desired time interval or a custom range and click **Apply**.

![](<../../../../.gitbook/assets/search conv history.png>)

5. At the top-right corner of the page, click **Refresh**.
6. The conversation block associated to the selected correlation ID appears in the table below the search criteria.

![](<../../../../.gitbook/assets/correlation id conversation.png>)

7. The errors that occurred for the provided correlation ID are marked with ![](../../../../.gitbook/assets/error.png).
8. Click the magnifier icon (![](<../../../../.gitbook/assets/magnifier icon.png>)) displayed inline with the error. The error details appear.

![](<../../../../.gitbook/assets/error details.png>)

The error description provides you with information on what is wrong. Based on the information provided here, do the proper changes to prevent the error from occurring again.

Note Flow and Flow Step where the error occurs. Go to **Flows** and search for the **Flow name**. Within the flow, search for **Flow Step**.
