## DRUID Release Life Cycle

DRUID Cloud environments are updated based on the following plan:

| Druid Cloud Environment | Druid version | Frequency | Contains |
| --- | --- | --- | --- |
| Druid Cloud Community  \*.community.Druidplatform.com | even & odd numbers  E.g. 1.38, 1.39, 1.40, 1.41 | every 2 weeks | Functionality developed for the current version number. |
| Druid Cloud Australia  \*.au.Druidplatform.com | odd numbers  E.g., 1.39, 1.41 | once per month | The features included in the last even version and the ones developed for the current odd version.  E.g., Druid v1.39 contains the functionality developed in the current version (that is, v1.39) and the features from v1.38 which has already been deployed on Druid Cloud Community, two weeks in advance. |
| Druid Cloud US  \*.US.Druidplatform.com | odd numbers  E.g., 1.39, 1.41 | once per month | The features included in the last even version and the ones developed for the current odd version.  E.g., Druid v1.39 contains the functionality developed in the current version (that is, v1.39) and the features from v1.38 which has already been deployed on Druid Cloud Community, two weeks in advance. |
| Druid Cloud West-Europe (PROD)  \*.Druidplatform.com | odd numbers  E.g., 1.39, 1.41 | once per month | The features included in the last even version and the ones developed for the current odd version.  E.g., Druid v1.39 contains the functionality developed in the current version (that is, v1.39) and the features from v1.38 which has already been deployed on Druid Cloud Community, two weeks in advance. |
