## What's New

- **NeuralSpace NLP provider**. DRUID is committed to provide authors with the possibility to use external NLP providers. This release introduces the NeuralSpace NLP provider.

![](../../Resources/Images/druid%205.9/neuralspace.png)

For information on how to set up the AI Agent Conversational AI to use the NeuralSpace NLP provider, see [Setting Up the AI Agent Conversational AI](../../Conversational%20AI/Setting%20Up%20the%20Conversational%20AI%20%28DRUID%20versions%20prior%20to%205.15%29.md).

- **AI Agent Conversational AI using only the Knowledge Base model**. When the Knowledge Base is used on the AI Agent, authors can set up their AI Agents to predict only within the Knowledge Base by setting the NLP provider to **None**.

![](../../Resources/Images/druid%205.9/kb%20none.png)

For more information , see [Setting Up the AI Agent Conversational AI](../../Conversational%20AI/Setting%20Up%20the%20Conversational%20AI%20%28DRUID%20versions%20prior%20to%205.15%29.md).

- **Instagram channel**. With this release, you can deploy AI Agents on Instagram using the Instagram Messenger from Meta enabling users to talk to your AI Agent using the Instagram app.

![](../../Resources/Images/druid%205.9/insta%20channel.png)

For more information, see [Instagram Integration](../../Channels/Instagram/Instagram%20Integration.md).

- **LINE channel**. With this release, you can deploy AI Agents on LINE enabling users to talk to your AI Agent using the LINE app.

![](../../Resources/Images/druid%205.9/line.png)

For more information, see [Instagram Integration](../../Channels/Instagram/Instagram%20Integration.md).
