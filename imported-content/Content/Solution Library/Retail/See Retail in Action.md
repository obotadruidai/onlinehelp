# See Retail Bot in Action

The list below provides you with an extensive list of things you can say to the AI Agent in either English or Romanian.

|  |  |
| --- | --- |
| Intents |  |
| English (EN) | Romanian (RO) |
| Do you have any special offers? | Aveti oferte speciale? |
| I want to buy a gift | Vreau sa cumpar un cadou |
| I want to return a product | Vreau sa returnez un produs |
| Where is my order | Unde este comanda mea? |
| I want to send a product to service | Vreau sa trimit un produs in service |
| How do I contact you? | Cum va pot contacta? |
| Do I have any valid warranties? | Am garantii valabile? |
| I have a complaint | Vreau sa fac o plangere |
| Do I have valid vouchers in my account? | Am vouchere valabile in contul meu? |
| I want to update my profile | Vreau sa imi actualizez profilul |
| Can I save the payment information into my account? | Pot sa salvez informatiile de plata in contul meu? |
| I want to see my reviews | Vreau sa vad review-urile mele |
| I want to change my delivery address | Vreau sa schimb adresa de livrare |
| I want to buy a gift card | Vreau sa cumpar un card cadou |
| Show me my orders | Arata comenzile mele |
| Show my wishlist | Arata-mi produsele favorite |
