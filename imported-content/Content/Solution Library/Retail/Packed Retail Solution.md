# Packed Retail Solution

This solution template provides conversation flows that guide the website visitors and customers through all the necessary steps to finding the perfect product, purchasing it, tracking an order, finding a specific product warranty, submitting a service request or a complain.

The Packed Retail solution contains all Druid retail solutions:

- [Customer Service](Customer%20Service/Customer%20Service.md)
- [Order Management](Order%20Management.md)
- [Product recommendation](Product%20recommendation.md)
- [FAQ](FAQ.md)
- [My account](My%20account.md)

<a id="Configurethetemplate"></a>

## Configure the template

After you import this solution, configure it following the procedure described in [Configuring Skill Templates](General%20Settings/Configuring%20Solution%20Templates.md).
