The archive contains folders for the following UiPath processes specifically designed for Druid Victor solution:

- Add Loan Request Process
- Attended Next Best Deal Process
- Loan Request Workflow Process
- Unattended Next Best Deal Process

Unzip the file, you will need the files later during the processes setup.

To set up UiPath Processes for Financial Services, follow these steps:

1. [Set up Victor\_Attended Next Best Deal Process](Step%201%20Set%20up%20Orchestrator.md).
2. [Set up Victor\_Unattended Next Best Deal Process](Step%202%20Set%20up%20Orchestrator.md).
3. [Set up Victor\_Advanced Process\_Data Service](Step%203%20Set%20up%20Orchestrator.md).
4. [Set up Victor\_Advanced Process\_Action Center](Step%204%20Set%20up%20Orchestrator.md).
