# KYC Retail Customer

This solution template provides you the onboarding process for the retail persona. It extracts relevant information mandatory in the KYC process by using Druid OCR engine for identity cards or MRZ readable model deployed in UiPath Ai Center with selfie matching and email confirmation.

<a id="Configurethetemplate"></a>

## Configure the template

After you import this solution, configure it following the procedure described in [Configuring Skill Templates](../General%20Settings/Configuring%20Solution%20Templates.md).
