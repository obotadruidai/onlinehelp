# Employee Update Personal Data

The HR AI Agent reads the information regarding current employee (integrated with the database of accounts). After the information is read, the data is shown to the user for data validation. If the user says the data is incorrect the AI Agent will ask what data needs to be modified.

Depending on the data that needs to be updated, AI Agents can use OCR of the identity card to extract information such as (first name, last name, identity card number, date of birth, document availability, etc) or the AI Agent can ask other relevant questions to update information regarding the employee like phone number, email address, work address or daily route to work. After the information is validated by the user the information is saved in your HR system.
