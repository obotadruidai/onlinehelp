<a id="DruidStarter"></a>


Each AI Agent should have it!

Install this solution from the Solutions Library to each AI Agent that you build. It includes definitions of system entities and common flows like Intent not recognized or Welcome flow.

Configure the Welcome and Intent Not Found flows in the AI Agent menu under Dialogue Management.

For information on how to install the solution, see [Installing Solution Templates](Installing%20Solution%20Templates.md).
