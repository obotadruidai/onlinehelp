# KBToolkit Release Notes

<a id="WhatsNewinVersion21"></a>

## What's New in Version 2.1

Discover the latest features and enhancements introduced in KBToolkit:

<a id="NewFeatures"></a>

### New Features

- Added support for the DRUID LLM Gateway, enabling seamless integration.
- KB Metadata is now separated from KBToolkit, providing two dedicated workspaces for better organization.
- Improved web views and forms user interface elements for a more user-friendly experience.

<a id="BugFixes"></a>

### Bug Fixes

- You can now delete test runs in bulk, saving time and effort.
- It is now possible to generate test cases directly within a test plan.

<a id="WhatsNewinVersion20"></a>

## What's New in Version 2.0

Learn about the key updates introduced in the previous version of KBToolkit:

<a id="NewFeatures1"></a>

### New Features

- Added support for managing Druid Conductor and orchestrated AI Agent configurations for improved scalability.
- Refactored workflows to streamline processes, consolidating all "Run" and "Evaluate" steps into a single flow.
- Removed hardcoded data, allowing for greater customization and adaptability.

<a id="BugFixes1"></a>

### Bug Fixes

- Fixed an issue where KB search records were not updated during the "Re-Run" process.
