# See the AI Agent in action

The list below provides you with an extensive list of things you can say to the AI Agent in either English or Portuguese.

| Functionality | Intent (EN) | Intent (PT) |
| --- | --- | --- |
| FAQ / Knowledge base | - My return flight is at 4 pm and I would like to know if you will charge me if I do the checkout at 2pm? - I will arrive around 10am at the hotel. what is the check-in hour? | - O meu voo de regresso é às 16h e gostaria de saber se me vão cobrar se fizer o checkout às 14h? - Chegarei por volta das 10h ao hotel. qual é o horário de check-in? |
| Book a room | - Can you help me to make a reservation? - Please help me to make a booking. | - Pode ajudar-me a fazer uma reserva? - Por favor ajudem-me a fazer uma reserva. |
| Check-in/Check-out | To show the Check-in and Check-out process go to “Bookings” section from workspace, select one booking with status “New” and from automation area click on Check-in. For Check-out search for a booking with status “Checked In” and from automation area click on Check-out. |  |
| Add a complaint | - I just checked in and I noticed that the remote control doesn't work. - The TV doesn't work in my room | - Acabei de fazer o check-in e reparei que o comando não funciona - A tv não funciona no meu quarto. |
| Complaint management | From “Complaints” section from workspace select one complaint and from automation area click on “Solve Complaint”. |  |
| Recommendations | - I am staying in Porto for 3 days, what are the best places to visit? - Where can I eat the best seafood in Porto? | - Vou ficar 3 dias no Porto, quais os melhores locais a visitar? - Onde posso comer o melhor marisco do Porto? |
| Collect feedback | To start the Collect feedback process, go to “Bookings” section from workspace select one booking with status “Checked Out” and from automation area click on Collect Feedback. |  |
| Cleaning process management | - I want to start the day. - What should I clean today? | - Quero começar o dia. - O que devo limpar hoje? |
