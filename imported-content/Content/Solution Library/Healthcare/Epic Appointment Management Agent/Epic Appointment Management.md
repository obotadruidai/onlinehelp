# Epic Appointment Management Agent

<a id="EpicAppointmentManagementAgent"></a>

## Epic Appointment Management Agent

This agent connects the Druid conversational AI experience directly to EPIC, giving patients real-time access to their information and appointments through natural conversation. Patients can check their existing bookings, find open appointment slots, and schedule new appointments — all without leaving the chat.

> **Info:** This is a demo solution intended for demonstration purposes.

<a id="KeyCapabilities"></a>

### Key Capabilities

- **Complete Appointment Lifecycle**. Manages the full lifecycle of patient visits, including booking and listing appointments.
- **Secure Patient Onboarding**. Supports Patient identification and account creation (with ID verification).
- **Multilingual Support**. The AI Agent detects and switches to any language instantly, ensuring a comfortable experience for every medic and patient.

<a id="KeyComponents"></a>

### Key Components

The main components of the solution include:

- Business Workflows:

- **Appointment Lifecycle Management** – Create and list medical appointment capabilities.
- **Patient Account Creation** – With secure ID verification.

- Two dedicated workspaces:

  - **Epic Appointment Settings** workspace — used by admins to configure Epic scheduling routes.
  - **Epic Patient Support** workspace — a provider-focused view used to access a patient’s 360 list of information.
- **Data Model**. Contains all essential appointment entities (Accounts, Appointments, and supporting nomenclatures).
