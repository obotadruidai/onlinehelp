# Manage Data Records

For medical back-office staff and solution admins

The **Order Medication Admin** workspace is the central repository for the AI Agent intelligence. It manages the nomenclatures (static data lists) that the AI Agent uses to categorize prescription needs and find the right medication.

<a id="EntityReference"></a>

## Entity Reference

The following table describes the core entities within the Order Medication data model and their specific roles in the patient journey:

| Entity | Description |
| --- | --- |
| Appointments | Stores info about the appointment, including the medical service (name, price), provider, facility and appointment details. |
| Account (Patient) | Stores patient profiles, including medical history (allergies, blood group), contact info, and insurance details. |
| Prescription | Stores the prescription record: start date, end date, refill frequency, prescribing provider, and its prescribed medications. |
| PrescriptionStatus | Tracks the Prescription lifecycle: New, In-Progress, Finished. |
| PrescribedMedication | A single medication line on a prescription — the medicament, dosage/strength, quantity to order, and instructions. |
| PrescriptionOrder | Stores the medication order record: prescription, pharmacy, status and ordered medications. |
| PrescriptionOrderStatus | Tracks the PrescriptionOrder lifecycle: Awaiting-Approval – has not been approved yet by the provider, In-Transit, Picked-Up. |
| PrescriptionRequest | A request generated by the refill agent for the prescribing provider to review — covers new/off-list medication requests, early refill requests, dosage change disputes, and order approval/signing requests. |
| RequestType | Nomenclature listing the valid PrescriptionRequest types (e.g. New Medication, Change Dosage, Early Delivery, Approve Order). |
| PrescriptionRequestStatus | Tracks the PrescriptionRequest lifecycle: Pending – awaiting provider approval, Approved, Declined. |
| Medication | The medication catalog searched when adding or replacing a medication — includes generic/brand/compound name and strength. |
| Facility (Pharmacy) | The physical locations where the orders are taken to. Includes addresses and postal codes. |
| PrescriptionFrequency | Nomenclature listing the valid refill frequencies (e.g. Weekly, Bi-Weekly, Monthly) available when creating or updating a prescription. |
| MedicationForm | Nomenclature listing the form a medicine (e.g. Capsule, Tablet, Patch) is found under. |
| MedicationRoute | Nomenclature listing the route a medicine (e.g. Intravenous, Nasal) is taken. |
| UnitOfMeasurement | Nomenclature listing the strength unit of a medicine (e.g. mg, ml,%). |

## Add New Data Records

You can manually add individual records at any time — for example, when adding new types of Medication.

To add a new record:

1. Select the **Order Medication Admin** workspace.
2. On the workspace menu, click the entity you wish to update (e.g., **Medication**).
3. Click the **Add** icon located in the upper right corner of the page.
4. Fill in the required fields. Ensure that relationships are maintained (e.g., when adding a medication, link the strength unit of the medicine). The required relationships can be found after the initial solution data provisioning.

![](../../../../../Resources/Images/Order%20Medication%20Agent/Manage%20Data%20Records.png)

5. Save the record.

<a id="EditRecords"></a>

## Edit Records

To edit a record:

1. Select the **Order Medication Admin** workspace.
2. On the workspace menu, click the entity you wish to update (e.g., **PrescriptionStatus**).
3. Click on the record you want to update.
4. Make the desired changes.

![](../../../../../Resources/Images/Order%20Medication%20Agent/Manage%20Data%20Records_1.png)

5. Save the record.
