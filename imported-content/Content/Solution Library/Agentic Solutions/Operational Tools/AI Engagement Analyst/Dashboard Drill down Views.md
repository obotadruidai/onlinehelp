# Dashboard Drill-down Views

The dashboards are fully interactive, enabling a seamless transition from high-level visual trends to granular conversation analysis details. This hierarchy allows you to validate AI assessments and perform deep-dive root cause analysis.

The table below describes the columns available in the conversation list view. These fields provide immediate context for each interaction before you dive into the full analysis.

| Column | Description |
| --- | --- |
| Started On | The exact date and time when the AI Analyst began processing the conversation transcript. |
| Channel Id | Identifies the communication channel used for interaction (e.g., Web, WhatsApp, Teams, etc.). |
| Origin | The specific URL of the web page where the user initiated the chat session. |
| AI Agent Turns | The total number of messages sent by the AI Agent during the conversation. |
| User Turns | The total number of messages sent by the user during the conversation. |
| Agent Turns | The total number of messages sent by a human agent (relevant for live chat escalations). |
| Outcome | The specific business goal or category identified for the interaction (e.g., Account Reset). |
| Resolution | The final success status of the interaction. |
| Clarity | The assigned clarity level based on how easy the dialogue was to follow. |
| Friction | The level of difficulty detected during the session. |
| Sentiment | The detected emotional tone of the user. |
| Human Review | A status indicator showing whether a staff member has manually verified the AI’s analysis for this record. |
| Language | The primary language detected by the AI Analyst during the interaction. |

For more information on inspecting these records, see [Conversation Detailed Analysis](Conversation%20Detailed%20Analysis.md).
