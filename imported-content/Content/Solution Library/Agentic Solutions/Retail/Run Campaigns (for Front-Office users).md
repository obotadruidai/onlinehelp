# Create and Run Campaigns (for Front-Office users)

Use campaigns to notify customers that products in their wish list are currently discounted. Before you can run a campaign, you must first create it.

<a id="Createacampaign"></a>

## Create a campaign

To create a campaign, follow these steps:

1. Select the **Retail Front-Office** workspace.
2. Click **Campaigns** on the workspace menu.
3. Click **New Campaign Promo**.

![](../../../Resources/Images/Retail/new%20promo.png)

4. Fill-in the following fields:

| Field | Description |
| --- | --- |
| Name | The unique name for this campaign. |
| Discount Code | The code that identifies the discount. The code is sent to the users by email. |
| Discount Percent | The percentage discount applied to qualifying products. |
| Start Date | The date the campaign begins. |
| End Date | The date the campaign ends. |

5. Toggle **IsActive** on.
6. Click the **Save** button to save the campaign and stay on the form.
7. Click the **Products** tab.
8. Add the products to include in the campaign:

1. Click the **Add** button.

![](../../../Resources/Images/Retail/save%20product%20icon.png)

2. Select the product from the dropdown.

![](../../../Resources/Images/Retail/select%20product.png)

3. Choose how to save:

- Click **Save & new** to save and add a new product.
- Click **Save & close** to save and close the form.

9. Save the campaign.

![](../../../Resources/Images/Retail/save%20campaign.png)

<a id="Runacampaign"></a>

## Run a campaign

> **NOTE:** Running a campaign sends a notification to all customers who have at least one campaign product in their wish list. Ensure the campaign is marked as active and that all dates are correct before running it.

Follow these steps to run an existing campaign:

1. Select the **Retail Front-Office** workspace.
2. Click **Campaigns** on the workspace menu.
3. Click the name of the campaign you want to run.
4. On the campaign form, click **Run Campaign**.

![](../../../Resources/Images/Retail/run%20campaign.png)
