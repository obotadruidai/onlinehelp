# Manually Run campaigns

for campaign managers

To manually launch a campaign, follow these steps:

1. Select **Campaigns & Contacts** from the workspace drop-down.
2. Click **Campaigns** on the workspace menu.
3. Click on the desired campaign.
4. Click the **Run Campaign** button.

![](<../../../../../.gitbook/assets/Manually Run campaigns_4.png>)

A chat window appears on the right-hand side of the screen, providing updates on the campaign launch. Close the chat window.

Click the **Run History** tab if you want to review the list of activities.

![](<../../../../../.gitbook/assets/Manually Run campaigns_5.png>)
