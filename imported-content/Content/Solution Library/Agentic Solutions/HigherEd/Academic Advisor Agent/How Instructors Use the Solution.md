<a id="HowInstructorsUsetheSolution"></a>


The Instructor workspace is dedicated to instructors, professors, lecturers, and teaching assistants. It enables them to add and manage the courses they teach across semesters, personalize course details (such as descriptions and prerequisites), and communicate with enrolled students by sending notifications directly from the workspace.

<a id="ManageCourses"></a>

## Manage Courses

The Instructor Course List displays all courses where the currently logged-in user is designated as the instructor.

To view your courses, go to the **Instructor** workspace menu and click **Instructor Courses**.

![](../../../../Resources/Images/HigherEd_Agentic_Advisor/instructor%20corse%20list.png)

You can manually add new courses, edit or delete existing ones.

To add a new course:

1. Click the **New Instructor Course** icon at the top right corner of the page.
2. On the form, fill in the following fields:

| Field | Description |
| --- | --- |
| Name | Select the course from the dropdown. |
| Instructor | Select your name from the dropdown. |
| Code | An unique identifier for the course. This field is automatically populated upon saving. |
| Description | A short summary of the course content. This field is automatically filled upon saving. |
| Prerequisites | Conditions that must be met before enrolling in the course. These can include:  - Prior courses - Program enrollment - Instructor approval |
| Department | The academic unit responsible for the course. This determines where the course is organized within the institutional structure and which programs can reference it. |
| Academic Period | The term or semester in which the course is offered. Used for scheduling and student enrollment planning. |
| Schedule | The planned timing of the course sessions. Typically includes:  - Day(s) of the week - Start and end time |
| Total Seats | The total number of seats available for this course. |
| Enrolled Seats | The number of students already enrolled in this course. This field does not require manual input, as it is automatically set to zero upon saving the form. |

3. Save and close the form.

<a id="SendNotifications"></a>

## Send Notifications

Instructors can send two types of messages: **Class Notifications**, addressed to all students enrolled in a course, and **Student Notifications**, addressed to an individual student. Both are powered by automations where the instructor composes the email content, which is then delivered to recipients through the Outlook channel.

<a id="SendClassNotifications"></a>

### Send Class Notifications

To send notifications to all students enrolled to a course:

1. Go to the **Instructor** workspace menu and click **Notifications** from the workspace menu.
2. Click on the **Course Notifications** tab.
3. Click the **Send Class Notification** button.

![](../../../../Resources/Images/HigherEd_Agentic_Advisor/course%20notif.png)

The chat window appears. Follow the guidance in the chat.

4. Select the course for which the notification is intended before composing the subject and body.

![](../../../../Resources/Images/HigherEd_Agentic_Advisor/select%20course.png)

5. Compose the notification (subject and body).

![](../../../../Resources/Images/HigherEd_Agentic_Advisor/compose%20email.png)

{% hint style="info" %}
**Info:** The instructor name, course name, and course code are automatically included in the email footer. You do not need to add them manually.
{% endhint %}

6. Send the notification.

{% hint style="warning" %}
**IMPORTANT!** You cannot send class notifications for a course without enrolled students. Attempting to do so will result in an error due to a lack of recipients.
{% endhint %}

You can also send a notification to all students enrolled to a course from the Instructor Course form.

![](../../../../Resources/Images/HigherEd_Agentic_Advisor/class%20notif%20form.png)

<a id="SendIndividualNotificationstoStudents"></a>

### Send Individual Notifications to Students

To send notification to an individual student:

1. Go to the **Instructor** workspace menu and click **Notifications** from the workspace menu.
2. Click on the **Instructor Student Notifications** tab.
3. Click the **Send Student Notification** button.

![](../../../../Resources/Images/HigherEd_Agentic_Advisor/student%20notif.png)

The chat window appears. Follow the guidance in the chat.

4. Enter the name of the enrolled student who will receive the notification.
5. Compose the notification (subject and body).
{% hint style="info" %}
**Info:** The instructor name, course name, and course code are automatically included in the email footer. You do not need to add them manually.
{% endhint %}

6. Send the notification.

You can also send a notification to an individual student from the Instructor Course form > Enrolled Students > student details form.

![](../../../../Resources/Images/HigherEd_Agentic_Advisor/stud%20notif%20form.png)
