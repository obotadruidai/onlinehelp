<a id="ReviewUpdateAgent"></a>


The Review & Update Agent modifies deployed AI Agents and upgrades legacy conversational structures.

<a id="KeyCapabilities"></a>

## Key Capabilities

- Analyzes active agent configurations and provides plain-language structural summaries.
- Prioritizes minimal configuration changes to adjust capabilities over rebuilding entire conversational flows.
- Upgrades legacy agent flows into agentic step formats while preserving existing business logic, connections, and system prompts.
- Prompts Data Modeler and Integrations Engineer automatically when modified AI Agent flows require new parameters.
- Configures record lookup verification checks automatically to ensure entity validation.
- Requests explicit confirmation before executing destructive operations, such as step or connection deletion.

<a id="OperationalRules"></a>

## Operational Rules

- Executes diagnostic fixes transferred from the Conversation Diagnostics Agent directly without redundant verification steps.
- Requires explicit verification for irreversible configuration removals regardless of trigger source.
