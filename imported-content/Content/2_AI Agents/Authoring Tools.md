<a id="AuthoringTools"></a>


The platform provides a comprehensive suite of manual configuration tools within the user interface. These authoring tools give you complete, granular control over every technical building block of your AI Agent, allowing you to design precise customer experiences and enterprise data connections.

Use these foundational UI components to build your AI Agent block by block:

- **Solutions**: Pack and manage all underlying assets (flows, entities, integrations) related to a specific business capability or project deployment.
- **Flows**: Use the Conversational Designer to manually construct multi-turn dialogue trees, decision blocks, and user-facing messages.
- **Entities**: Define your structural backend data model and storage layers to record, validate, and track user inputs during active sessions.
- **Integrations**: Configures connectors, external REST API payloads, and internal data operations to integrate your AI Agent with third-party enterprise platforms.
- **Channels**: Deploy your AI Agent across voice, chat, or social media networks.
