# Conversational Designer

The Conversational Designer is the AI Authoring Agent responsible for understanding your business use case and drafting the underlying conversational flow skeleton. It builds the interactive capabilities and dialog flows required for user engagement and determines what data structures are needed to support the interaction.

<a id="KeyCapabilities"></a>

## Key Capabilities

- Translates plain-language business requirements into structured conversational flows, message sequences, and execution paths.
- Creates interactive dialog elements, sets up conversation steps, and configures user engagement paths.
- Identifies the data structures, records, and variables required to support the conversational flow.
- Generates sample phrases, intent triggers, and slot parameters to route users into the conversation flow effectively.
- Displays a clear preview of proposed flow structures, actions, and triggers for user confirmation before building.

<a id="OperationalRules"></a>

## Operational Rules

- Works through flow setup sequentially to ensure complete step-by-step traceability.
- Requires explicit user approval before applying changes or generating conversation flows.
- Focuses on conversation logic and hands off non-conversational tasks—such as creating visual charts or executing test suites—to designated specialized agents.
