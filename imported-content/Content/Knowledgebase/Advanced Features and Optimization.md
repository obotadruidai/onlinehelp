# Advanced Features and Optimization

Beyond standard document ingestion, Druid provides powerful controls to fine-tune how your AI Agent retrieves, processes, and validates knowledge-base answers during live user conversations.

The Advanced Features & Optimization section covers deep configuration options designed to maximize answer accuracy and relevance. Explore these topics to learn about:

- **KB Metadata**. Tagging and filtering content to dynamically restrict or target search results based on user variables or attributes.
- **Conversation-Time Management**. Customizing how the AI Agent handles search queries and formats answers mid-dialogue.
- **Advanced Extraction Tools**. Converting specialized media types, such as video files, into searchable text.
- **LLM Validation**. Implementing guardrails to review, validate, and secure LLM-generated responses before they reach the end user.

Use these advanced configurations to transition your Knowledge Base from a basic search index to a highly optimized, context-aware conversational engine
