# Live Chat

Live Chat allows authors to create AI Agents which handle rich conversations. While AI Agents are always active and can engage your clients 24×7 by answering their simple FAQs promptly, live chat is a better solution when the customers prefer talking to a human or when the AI Agent fails to understand customer issues and assistance from the support team is needed.

DRUID authors can configure the AI Agents to handle repetitive questions and route customer queries to live agents.

<a id="DRUIDLiveChatKeyFeatures"></a>

## DRUID Live Chat Key Features

- Route to a live agent when the customer queries need further discussion or when the customer prefers talking to an agent.
- Multi-chat. Live agents can handle multiple conversations simultaneously.
- Sound notifications for live agents whenever a new client is added to the waiting queue.
- AI Agent delivers to agents quick info cards (Customer 360, Contract 360) linked with the conversation context.
- Notification when a client is connected to an agent.

<a id="WhyusingLiveChatwithAIAgents"></a>

## Why using Live Chat with AI Agents?

Adding Live Chat to your AI Agent can help your business significantly:

- Boost customer satisfaction with live conversations.
- Increase your support team efficiency.

<a id="Howitworks"></a>

## How it works

The diagram below describes how a AI Agent handles Live Chat.

![](../Resources/Images/Live%20Chat/live%20chat%20diagram.png)

1. The user starts chatting with the AI Agent. The AI Agent chats with the user in an automated conversation.
2. The user chooses to talk to a live agent so, the AI Agent directs the user to Live Chat, adds the user to the Waiting queue from where the chat is picked up by a live agent.
3. Once the conversation between the user and a live agent ends, the user continues talking to the AI Agent in an automated fashion, that is the AI Agent provides the user with automated messages.
