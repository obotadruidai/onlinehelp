To help you understand how to customize the Live Chat Starter so that you have a live chat solution that best suits your needs, this section describes how the AI Agent handles live chat from different perspectives based on the predefined Live Chat Starter flows.

The diagram below illustrates all the events during the live chat lifecycle. You gave the option to personalize each such event, according with your specific needs: conversation topic, values within the context (amounts), AI Agent personality etc.

![](../Resources/Images/Live%20Chat/live%20chat%20steps.png)

In a live chat there are two chat activities kept in sync by the AI Agent.

1. [Chat with the client](Handling%20live%20chat%20on%20client%20side.md).
2. [Chat with the agent](Handling%20live%20chat%20on%20Agent%20side.md).
