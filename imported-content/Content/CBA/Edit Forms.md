# Edit Forms

The following actions are available on forms in the Forms list: make default (a form that is not set as being default view), preview, clone, edit and delete.

You can edit a form by changing: the form properties (name, display name), the form layout (tabs, sections, fields) and the form data (add or delete integrations).

<a id="ActionsavailableonformsinFormDiagram"></a>

## Actions available on forms in Form Diagram

When in Form Diagram, you can perform the following actions:

- View the form structure in a tree view by clicking the **Form tree view** icon (![](../Resources/Images/CBA/form%20tree%20view.png)) on the left pane.
- Reorder the tabs in a form by clicking placing the mouse over the tab name and clicking the left or right arrow to move the tab to the left or to the right based on your needs.
- Reorder sections and fields within a section by using drag and drop.
- Move a field from a section to another one by using drag and drop.
- Edit a field of the current entity. Click on the field and at the top-right corner of the field, click the **Edit** icon. The Edit entity field page appears and you can edit the **Display name**, mask the field data if it captures user sensitive data or match entities records aligned with the business user language. For more information, see [Extensive Sensitive Data Manipulation](../Governance%20%26%20Security/Extensive%20Sensitive%20Data%20Manipulation.md) and [Multilingual Entity Fields](../5_Entities/Multilingual%20Entity%20Fields.md).
- Delete fields from the current entity. Click on the field and at the top-right corner of the field, click the **Delete** icon. A warning message appears. Click **Yes** to confirm the field deletion.

> **IMPORTANT!**  Deleting fields from the system cannot be undone; therefore, we recommend you to review the AI Agent informational model carefully before deletion.
