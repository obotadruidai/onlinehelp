---
title: "Set a Default Landing Workspace for Business Users"
---

<a id="SetaDefaultLandingWorkspaceforBusinessUsers"></a>


If business users have access to multiple workspaces within a AI Agent, you can set a default workspace that appears when they log in.

To set a default workspace:

1. On the **Administration** menu, click **Users**.
2. Locate the desired user, click **Actions**, and select **Edit**.
3. In the User Configuration page, click the **Defaults** tab.
4. Select the AI Agent and the workspace you want as the default.

![](../Resources/Images/druid%205.15/default%20workspace%20set.png)

5. Click **Save**.

When users log into the Druid Portal, the selected workspace will load automatically. If they have access to multiple workspaces, they can switch to another one using the Workspaces drop-down menu.

![](../Resources/Images/druid%205.15/default%20workspace.png)
