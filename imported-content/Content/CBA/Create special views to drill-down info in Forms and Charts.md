# Create Special Views for Forms and Charts

In DRUID 5.16 and higher, you can create special views to provide business users with more information about fields displayed in forms, fields of type entity or entity list. You can also create a special view to provide business users with more detailed insights by drilling down in charts.

To create a special view, follow the [Create and design views](Create%20and%20Design%20Views.md) making sure to select the view **Type** based on what you want to do. The table below provides a short description of the special view types you can create in DRUID.

| View Type | Description |
| --- | --- |
| Sub Grid | View you can set on form entity fields of type Entity List to provide the users with more information. |
| Lookup | View you can set on form entity fields of type Entity to provide the users with more information. |
| Chart Drilldown | View you can set on charts to provide the users with more information when clicking on charts. |

> **NOTE:** The special views are available for use only when authoring the entity forms and charts. They are not available in Workspaces views nor in the Data tab on entities.
