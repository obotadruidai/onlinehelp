# Edit Views

The following actions are available on views in the View list: make default (a view that is not set as being default view), preview, clone, edit and delete.

![](../Resources/Images/CBA/views%20actions.png)

You can edit a view by changing: the view properties (name, display name and description), the view columns (reorder, add or delete columns), the column properties or the view data (add or delete integrations).
