# Thumbnail

Thumbnail steps work similarly to Hero steps, but with a more compact layout for the card images. While Hero cards feature larger, more prominent images, Thumbnail cards present the same information in a smaller format.

To add and configure a Thumbnail step in a DRUID flow:

1. Open the desired flow in Flow Diagram view.
2. Expand the Flow Palette, then drag the **Message** step from the Dialog category into the main flow window and drop it onto the step you want to link it to.
3. Select the step on the diagram, then click the **Settings** icon from the Actions menu.
4. Configure the step following the same procedure as for [Hero Card](Hero%20Steps%20Configuration.md) steps.
