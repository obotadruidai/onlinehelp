# Integrations

The Druid AI Platform provides a high-performance connectivity framework designed to link AI Agents with your broader enterprise ecosystem. By leveraging these integrations, agents move beyond simple conversation—they gain the ability to query databases, trigger complex business workflows, and process multi-modal data in real-time.

Druid categorizes these connectivity methods into three distinct pillars based on their technical architecture and communication patterns:

- **Enterprise Connectors**. The core mechanism for synchronous communication with backend systems. These connectors allow agents to interact with ERP, CRM, and RPA platforms (such as SAP, Salesforce, and UiPath) using standardized protocols like REST, SOAP, and direct SQL queries.
- **Webhooks**. A powerful framework for event-driven, asynchronous communication. Webhooks allow Druid to react to external triggers (Inbound) or push real-time notifications and data updates to third-party applications (Outbound) without a manual request from the user.
- **Druid Vision**. A specialized suite of Visual AI services consumed via REST endpoints. This integration enables agents to interpret and extract data from images, documents, and physical objects, transforming visual input into actionable conversational data.
