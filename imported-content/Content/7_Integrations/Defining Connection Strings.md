<a id="DefiningConnectionStringsApps"></a>


Once you define the data model (the [entities](../5_Entities/AI%20Agent%20Informational%20Model.md)) the AI Agent uses to collect and store information), you can define the connection strings (apps) used for integration with third-party applications. Connection strings provide specific connection details.

To define an app within the selected solution, click **Apps** on the main menu. The Apps page appears, listing the existing apps for the selected solution.

In the top-right corner of the page, click **Create App** and select the app type based on the integration type supported by the third-party application.

![](../Resources/Images/Integrations/Creating%20Druid%20Connectors.png)

The New App page appears. The page content varies based on the selected integration type. For more information, see the respective connector section.
