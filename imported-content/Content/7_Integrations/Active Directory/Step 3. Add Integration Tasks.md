---
title: "Step 3. Add Integration Tasks"
---

<a id="Step3AddIntegrationTasks"></a>


At the top-right corner of the Edit Connector Action page, **Connector steps** tab, from the **Create task** dropdown, select **Active Directory**, and then click the specific Active Directory task:

- **Search** – search user(s) in AD.
- **Unlock user** – unlock a user in AD.
- **Add user to group** – add existing user to a group in Active Directory.
- **Reset Password** – reset the password of existing users.

![](../../Resources/Images/AD/tasks%20list.png)

The subsequent sections describe how to add and configure the different AD integration tasks.
