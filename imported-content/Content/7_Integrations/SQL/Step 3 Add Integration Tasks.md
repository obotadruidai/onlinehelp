---
title: "Step 3. Add Integration Tasks"
---

<a id="Step3AddIntegrationTasks"></a>


At the top-right corner of the Edit Connector Action page, **ConnectorSteps** tab, click on the **Create Task** button, and then click **Sql Server**.

![](../../Resources/Images/SQL%20Connector/Step%203%20Add%20Integration%20Tasks.png)

The Edit Connector Task page appears by default on the **General** tab.

![](../../Resources/Images/SQL%20Connector/Step%203%20Add%20Integration%20Tasks_1.png)

When adding an SQL task, you have to:

1. [Set the task general parameters](General%20Settings.md).
2. [Write the statement to the SQL database](Request%20Settings.md).
3. [Map the response into the conversation context](Response%20Settings.md).
4. [Test the integration call](Testing%20Settings.md).
