# Step 3. Add Integration Tasks

At the top-right corner of the Edit Connector Action page, **ConnectorSteps** tab, click on the **Create Task** button, and then click **Sql Server**.

![](<../../../.gitbook/assets/Step 3 Add Integration Tasks.png>)

The Edit Connector Task page appears by default on the **General** tab.

![](<../../../.gitbook/assets/Step 3 Add Integration Tasks_1.png>)

When adding an SQL task, you have to:

1. [Set the task general parameters](<General Settings.md>).
2. [Write the statement to the SQL database](<Request Settings.md>).
3. [Map the response into the conversation context](<Response Settings.md>).
4. [Test the integration call](<Testing Settings.md>).
