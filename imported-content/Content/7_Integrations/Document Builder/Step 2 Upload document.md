# Step 2. Upload document

1. Log in the Druid Portal, select the AI Agent and solution.
2. On the main menu, click **Documents**. The list of documents templates appears.
3. At the top-right corner of the page, click the **CreateNewTemplate** button. The **CreateOrUpdateNewDocumentTemplateMetadata** page appears.
4. Enter a **Name** and **Category** for the file to upload.
5. Browse for the desired document template (either Word or Excel) and select it.

![](../../Resources/Images/Document%20Builder/Step%202%20Upload%20document.png)

6. Click **Save**. You can now add the integration task for generating documents using your template.
