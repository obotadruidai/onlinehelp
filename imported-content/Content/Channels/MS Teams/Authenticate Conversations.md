# Authenticate Conversations with SSO Teams

> **NOTE:**  This functionality is available in DRUID version 1.60 or higher.

For AI Agents operating in the back-office in applications that use Azure AD authentication (e.g., Office 365 applications), authors can set the AI Agents to operate on behalf of the users by using a token generated by the user’s Azure AD client.

For example, a user asks the AI Agent in the Teams channel to add appointments to their Outlook calendar.

<a id="Howitworks"></a>

## How it works

1. The user gives the Teams AI Agent the permission to obtain an authentication token from their Azure AD client.
2. The AI Agent will use that token to operate on behalf of the users in Office 365 applications.
3. The actions performed by the AI Agent on behalf of the user will be logged as being performed by the user.

<a id="HowtosetauthenticationwithSSOTeams"></a>

## How to set authentication with SSO Teams

<a id="Prerequisites"></a>

### Prerequisites

- You have the Teams channel active.
- You have an Azure AD tenant and admin account credentials.
- In Developer Portal you added to your AI Agent settings (**Configure** menu > **Domains**) the following domains:

- `token.botframework.com`
- DRUID API domain that is specific to the DRUID Cloud you're using:

| DRUID Community | PROD Europe | PROD US | PROD Australia |
| --- | --- | --- | --- |
| `druidapi.comm.eu.druidplatform.com` | `prod-DRUID-api.azurewebsites.net` | `druidapi.us.druidplatform.com` | `druidapi.au.druidplatform.com` |

<a id="Step1CreateTeamsSSOflow"></a>

### Step 1. Create Teams SSO flow.

1. Create a flow for Teams SSO authentication and add a step of type Teams SSO.

![](../../Resources/Images/Conversation%20Authentication%20SSO%20Teams/Authenticate%20Conversations.png)

This flow step will display a sign in button in the chat (Teams channel).

2. Configure the step.

You can add the user to specific additional roles.

Type the sign in button label (the text that will be displayed on the sign in button) in AI Agent default language and additional language(s).

![](../../Resources/Images/Conversation%20Authentication%20SSO%20Teams/Authenticate%20Conversations_1.png)

3. Mark the step as first and last step and save the step.

<a id="Step2RegisteryourAIAgentthroughtheAzureADportal"></a>

### Step 2. Register your AI Agent through the Azure AD portal

In your Azure AD tenant, register your AI Agent following the procedure described in [Microsoft documentation](https://docs.microsoft.com/en-us/microsoftteams/platform/bots/how-to/authentication/auth-aad-sso-bots).

<a id="Step3UsetheSSOToken"></a>

### Step 3. Use the SSO Token

When the Teams SSO step is executed (the user clicks the sign in button in the chat via the Teams channel), DRUID stores the token generated by Azure AD in the system field **[[ChatUser]].SSOToken**.

You can further use the value from this field in integrations on the header of REST calls. In this case, the authentication on REST calls is no longer required.
