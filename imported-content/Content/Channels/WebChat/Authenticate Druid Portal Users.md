# Authenticate Druid Portal Users

If you're using the web chat from within the Druid Portal, you can authenticate your conversation. When you first open the web chat, your conversation is anonymous.

![](<../../../.gitbook/assets/anonymous conv.png>)

{% hint style="warning" %}
**IMPORTANT!** This authentication feature is only available when you access the web chat directly from the Druid Portal.
{% endhint %}

To log in, click the **Login** icon in the web chat header.

![](../../../.gitbook/assets/login.png)

Druid will automatically authenticate you as a Portal user, and the conversation becomes authenticated.

![](<../../../.gitbook/assets/auth conv.png>)

To log out, click the **Logout** icon.

![](<../../../.gitbook/assets/log out.png>)

A new, unauthenticated conversation will begin.
