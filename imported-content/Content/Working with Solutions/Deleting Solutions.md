---
title: "Delete Solutions"
---

<a id="DeleteSolutions"></a>


Deleting a solution removes from the system only the solution package and not the elements included in the solution. All the configuration elements remain associated with the original AI Agent and are available to be included in other solutions.

To delete a solution package, in the solution configuration page, at the bottom of the page, click the **Delete** button.

![](../Resources/Images/Working%20with%20solutions/Deleting%20Solutions.png)

A confirmation pop-up appears.

![](../Resources/Images/Working%20with%20solutions/Deleting%20Solutions_1.png)

Click **Yes** to confirm deletion. The Solutions page appears and you can see that the selected solution was removed from the system (it no longer displays in the list of solutions).

> **NOTE:**
>
> - A flow unlinked from the solution still remains at the AI Agent level.
> - You can link a specific configuration element (flow, connector action, entity, document template, etc.) to multiple solutions at the same time. This means that the configuration element is part of multiple configurations; the element is not multiplied.

You can edit the configuration elements at the AI Agent level.

To see the list of configurations elements from all AI Agents, on the main menu, click **All Settings** and then click the type of elements you want to see (flows, entities, etc.).

![](../Resources/Images/Working%20with%20solutions/Deleting%20Solutions_2.png)
