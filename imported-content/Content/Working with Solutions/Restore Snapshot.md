# Restore Snapshot

> **NOTE:** Restoring a solution snapshot overwrites the current elements included in the solution with the ones from the snapshot.

To restore a snapshot, follow these steps:

1. In the solution configuration page, click the Solution Snapshots section header. The section expands.
2. Click the **Restore** icon displayed in line with the snapshot you want to restore.

![](../Resources/Images/Working%20with%20solutions/Restore%20Snapshot_1.png)

3. A pop-up appears. Click **Yes** to confirm the snapshot restore operation. After the restoring completes successfully, “RestoreSnapshot” displays in the **Operation** column.

![](../Resources/Images/Working%20with%20solutions/Restore%20Snapshot_3.png)

4. Click the **Refresh** button at the top-right side of the table until the snapshot status changes from **Pending** to **Success**.
