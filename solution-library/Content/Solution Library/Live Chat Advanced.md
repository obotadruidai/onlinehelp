<a id="LiveChatAdvanced"></a>


This solution provides you with configurations for powerful route-to-human functionality:

- Transfer live chat call to specific queue.
- Transfer live conversation from an agent to another.

Install this solution from the Solutions Library. For information on how to install the solution, see [Installing Solution Templates](Installing%20Solution%20Templates.md).

## How to set up Live Chat Advanced
