<a id="UiPathAttendedProcess"></a>


Interacting with your personal, locally installed UiPath robot is now easier than ever, thanks to the integration of Robot.JS framework in DRUID webchat resources.

The process includes UiPath integration with attended automation. Contact Center Agent is chatting with the AI Agent and triggers an attended automation.

{% hint style="info" %}
**NOTE:** You need a UiPath tenant but you can easily open a free Community subscription.
{% endhint %}

1. Download the UiPath process.

[!\[\](../Resources/Images/Download.png)](https://druiddocs.file.core.windows.net/docs-shares/Druid_StartingPack_Attended.zip?st=2022-01-18T11%3A36%3A25Z&se=2026-01-19T11%3A36%3A00Z&sp=rl&sv=2018-03-28&sr=f&sig=2mj4zunLFZVkElMYhHQhqL3PEv8wIgrFOVoLIKNqKNw%3D)

2. On the desired AI Agent, import the **Druid\_StartingPack\_Attended**.zip file. For information on how to import solutions, see [Importing Solutions](https://druidai.gitbook.io/druid-ai-docs/release-lifecycle-and-versioning/importing-solutions).
3. Customize the process based on your needs. For more details, see [Integrating Using Robot.JS](<https://docs.druidai.com/docs/Content/7_Integrations/UiPath/Integrating%20Using%20Robot.JS.htm>).
