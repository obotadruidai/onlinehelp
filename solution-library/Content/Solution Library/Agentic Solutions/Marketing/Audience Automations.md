---
title: Audience Automations
---


The Audiences view and form provide automations to help you import audience members or reset member statuses efficiently.

To access Audiences, select the **Campaigns & Contacts** workspace and click **Audiences** on the workspace menu.

## Import audience

Use this process to create a new audience and populate it with members using an Excel file.

1. Click the **Import Audience** button.

![](<../../../../.gitbook/assets/improt audience.png>)

2. In the chat window, enter a name for your audience when prompted.

![](<../../../../.gitbook/assets/audience name.png>)

3. Download the provided Excel template.

![](<../../../../.gitbook/assets/download template (1).png>)

4. Fill it in with your audience details and save the file.
5. In the chat window, click **Yes**, then upload the completed file.

[\<https://druiddocs.file.core.windows.net/docs-shares/Rebranded/DRUID Hybrid Deployment on Windows\_20260922.pdf?sv=2025-07-05\&spr=https\&st=2026-09-22T12%3A14%3A06Z\&se=2030-09-23T12%3A14%3A00Z\&sr=f\&sp=r\&sig=OO1pBaGpzaXs88CK3qpO33v6L%2BwZPnh%2FpQTYPA1Klzk%3D>](../../../Solution%20Library/Agentic%20Solutions/Marketing/https:/druiddocs.file.core.windows.net/docs-shares/Rebranded/DRUID%20Hybrid%20Deployment%20on%20Windows_20260922.pdf)![](<../../../../.gitbook/assets/upload audience.png>)

The new audience is created and displayed in the audience view.

## Reset audience members status

Use this process to restore the status of audience members back to **New** so the audience can be reused in future campaigns.

1. Select the target audience from the list in the Audiences view.
2. On the audience details form, click the **Reset Statuses** button.

![](<../../../../.gitbook/assets/reset status.png>)

3. The chat panel opens on the right displaying a confirmation message indicating that the members' status has been reset.

![](<../../../../.gitbook/assets/confirm reset msg.png>)

4. Close the chat window to see the status **New** updated for all members.

![](<../../../../.gitbook/assets/status new.png>)
