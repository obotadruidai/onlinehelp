For medical providers

The **Order Medication Management** workspace allows staff to manage the complete prescription lifecycle. This ensures that every medication order is tracked from generation through to the final reorder.

## Generate a Prescription

Medical staff and doctors should perform the following steps only when a patient has honored their appointment:

1. Select the **Order Medication Management** workspace.
2. Click **Appointments** on the workspace menu.
3. Select the appointment which the patient honored. The appointment form opens.
4. From here, there are two ways to start the prescription process, using the two buttons at the top right corner of the form:

* Click the **Complete Appointment** button. This marks the appointment as completed. The Chat window opens on the right to inform the user that the appointment was successfully completed, and asks if they wish to start the prescription creation process.
* Click the **Prescribe** button. The Chat window opens on the right and goes straight into the guided flow.

![](<../../../../../../.gitbook/assets/How to Use the Solution.png>)

Once in the guided flow (from either path), the AI Agent gathers each medication, its instructions, and the prescription's duration and refill frequency (for a new prescription), or the requested change (for an existing one).

## Process a Prescription Request

Medical staff and doctors should perform the following steps to review and act on a prescription request generated by the patient about their medication order:

1. Select the **Order Medication Management** workspace.
2. Click **Prescription Request** on the workspace menu.
3. Select the prescription request to review. The request form opens.

![](<../../../../../../.gitbook/assets/How to Use the Solution_1.png>)

4. Click the **Process Prescription** button. Depending on the request type, the flow will help the medic process the request and send a notification to the patient based on the result.
