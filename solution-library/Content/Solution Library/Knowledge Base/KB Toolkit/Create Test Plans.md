---
title: Test Plans
---


Test plans help you organize and group test cases with a specific focus. By grouping multiple test cases, you can focus attention to a particular content area. Test plans also make it easy to run bulk tests whenever changes are made to your AI Agent or KB, ensuring consistent performance and accuracy.

A well-structured test plan streamlines testing efforts and ensures thorough coverage of critical areas.

## Create test plan

To create a test plan, follow these steps:

1. On the workspace menu, click **KB Test Plans**. The Test Plan page appears.
2. In the Test Plan page, click the **New Record** icon in the top-right corner. This opens the Test Plan creation page, which defaults to the **Details** tab.
3. Enter the test plan **Name** and select the **AI Agent**.

![](<../../../../.gitbook/assets/test plan create.png>)

4. Click the **Save** icon to save the test plan details.

You can now add test cases to the test plan.

## Add test cases

To add test cases to a test plan, follow these steps:

1. From the **Automations** drop-down, select **Export Test Casesto Excel**.

![](<../../../../.gitbook/assets/test plan exports test.png>)

A chat window appears on the right-hand side of the screen, providing you with the export link.

2. Click on the download link provided in the chat to download the template on your computer.

![](<../../../../.gitbook/assets/export link for test plan.png>)

3. Close the Chat window.
4. Open the file, keep only the test cases you want to include in the current test plan, and then save the updated file.
5. In the test plan configuration page, click the **Test Cases** tab.
6. From the **Automations** drop-down, select **Import from Excel**.

![](<../../../../.gitbook/assets/import from excel.png>)

7. Upload the test case Excel file in the chat window on the right-hand side of the screen. Use the **Upload** button to add it.
8. Wait for the import process to complete. Once finished, close the chat window. The test cases will be successfully added to the test plan.

![](<../../../../.gitbook/assets/imported tests.png>)

{% hint style="info" %}
**Info:** To add a single test case, go to the Test Cases section and click the Add New Record button. In the **TestCase** field, select the desired test case from the list, then click **Save & Close**.

<img src="../../../../.gitbook/assets/Testcase select.png" alt="" data-size="original">
{% endhint %}

9. After you finish adding the desired test cases to the test plan, click **Save & close** to save the test plan and exit the configuration page.

![](<../../../../.gitbook/assets/save test plan and exit.png>)

Create as many test plans as needed to cover the specific areas of the KB data sources you want to test.

You can now run test plans.
