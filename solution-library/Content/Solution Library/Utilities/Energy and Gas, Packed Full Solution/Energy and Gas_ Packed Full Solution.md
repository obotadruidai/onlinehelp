<a id="EnergyandGasPackedFullSolution"></a>


This solution template provides a smart way to scale exceptional customer experiences. It includes conversation flows for submitting online complaints by asking the relevant details about the incident, update customer contract, see invoice details, transmit self-read index and more.

This solution template provides a wide range of skills for customers:

| Skill | Description |
| --- | --- |
| Query Sold | Shows the account balance query and the list of unpaid invoices. |
| GDPR Agreement | Displays information related to the GDPR and allows the clients to update (give / withdraw) their consent. |
| Complaints | Registers online complaints by asking the user relevant details about the incident. |
| Contract Data Update | Guides the user easily update the contract data. |
| Electronic Invoice Activation | Enables the user to activate the issuance of the invoice in electronic format. |
| MyElectricity Account Creation | Enables the user to create an online account with the electricity provider. |
| New Contract | Guides the user to add a new contract. |
| Invoice Information | Provides information on the user’s last invoice. |
| Tariff Information | Provides rates information. |
| Self-reading Index | Enables the user to transmit the self-read index. |
| Consumer Convention Update | Find out more about and modify the Consumer Convention. |
| Date of Issue Notice | Find out the date of issuance notice in case of unpaid overdue invoices. |
| Utilities Offer | Provide detailed offer related to utilities. |
| Regularization Invoice Complaint | Register online complaints related to regularization invoices. |
| Invoice not issued | Register online complaints related to invoices not issued. |
| Wrong estimated power consumption | Register online complaints related to wrong estimated power consumption. |
| Non-issuing physical invoice | Register online complaints related to non-issuing physical invoices. |
| Voltage fluctuations | Register online complaints related to voltage fluctuations. |
| Defective Counter | Report a defective counter. |
| FAQ | Provides the users with predefined answers to a comprehensive set of questions related to contracts, invoices and indexes. |
