title: Loan Request
---


This solution template provides you with the basic configuration to be used in financial services for loan requests.

Druid identifies the intent of the user and guides the user to choose the desired product, asking reliable questions that would rather be asked by the banking officer. Druid automatically creates the loan request based on the information captured in the conversation.

The customers (active accounts) can apply online for a loan, being able to provide online the information / documents required to apply for a loan, without having to stress about going physically in a bank agency and talk to a bank representative.
