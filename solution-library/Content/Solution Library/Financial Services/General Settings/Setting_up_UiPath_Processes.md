title: Setting up the UiPath Process
---


Download Victor specific UiPath processes by clicking on the **Download** button below and unzip it.

[!\[\](../../../Resources/Images/Download.png)](../../../Solution%20Library/Financial%20Services/General%20Settings/https:/druiddocs.file.core.windows.net/docs-shares/Victor/UiPath%20Processes.zip)

The archive contains folders for the following UiPath processes specifically designed for Druid Victor solution:

* Add Loan Request Process
* Attended Next Best Deal Process
* Loan Request Workflow Process
* Unattended Next Best Deal Process

Unzip the file, you will need the files later during the processes setup.

To set up UiPath Processes for Financial Services, follow these steps:

1. [Set up Victor\_Attended Next Best Deal Process](<Step 1 Set up Orchestrator.md>).
2. [Set up Victor\_Unattended Next Best Deal Process](<Step 2 Set up Orchestrator.md>).
3. [Set up Victor\_Advanced Process\_Data Service](<Step 3 Set up Orchestrator.md>).
4. [Set up Victor\_Advanced Process\_Action Center](<Step 4 Set up Orchestrator.md>).
