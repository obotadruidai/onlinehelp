<a id="SettingUptheWebChatinHTMLPage"></a>


This section provides you with a HTML page template (a .txt. file) that contains web chat. You can download it and easily configure it to include your AI Agent. You can use this HTML page to see Human Resources in action.

Download the HTML website page template (**Chatbot-Cristina.txt** file), then integrate Human Resources into the HTML page.

For more information on how to integrate the AI Agent in your website and access more HTML templates, see [WebChat](https://druidai.gitbook.io/druid-ai-docs/channels/web-and-email/webchat).
